# Meech213 portfolio recreation

A scroll-driven photography and film portfolio recreation with a full-screen visual scene, project index, and individual project routes.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

`public/_redirects` provides the SPA fallback needed for direct project links such as `/photo/kelly-rowland-for-grazia` on static hosts.
